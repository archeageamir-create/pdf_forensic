# Document Forensic Inspector

Локальное Windows-приложение для исследования файлов в едином графическом
интерфейсе. Оригинал открывается только для чтения: программа считает
его SHA-256, создаёт отдельную рабочую копию и передаёт анализаторам только её.

## Универсальная версия в разработке

Текущая ветка расширяет PDF-лабораторию версии 0.4.2. Добавлены:

- PDF, PPTX, DOCX, XLSX, изображения, медиа и ZIP; формат определяется по содержимому;
- карточка файла с главными сведениями, областью проверки и наблюдениями простым языком;
- общий поиск по метаданным, фильтр «Требует внимания», источник и исходное значение каждого факта;
- поиск по всем сохранённым метаданным выбранного проекта с переходом к конкретной находке;
- EXIF/GPS и предпросмотр изображений, исправления и комментарии Word, скрытые листы Excel;
- ffprobe: контейнер, дорожки, кодеки, длительность и теги аудио/видео;
- каталог ZIP без извлечения и базовая карточка неизвестного формата;
- постоянная очередь SQLite: пакетный импорт, отмена, повтор и восстановление после перезапуска;
- наблюдаемые папки: новые и изменённые файлы автоматически поступают в выбранный проект;
- отдельный процесс на каждый файл, общий лимит времени и ограниченный вывод утилит;
- автосохранение экспертных заметок, защита оригиналов от перезаписи отчётом.

## Существующие возможности PDF-лаборатории

Автор оболочки, интеграции и сборки: **Amirkhan Smagulov**. Приложение объединяет
независимые open-source компоненты; автор оболочки не заявляет авторство или права
на ExifTool, qpdf, pdfcpu, Poppler, JHOVE, veraPDF, Apache PDFBox, PDFiD,
pdf-parser и другие сторонние библиотеки.

- проекты и карточки исследований, пакетное добавление файлов и drag-and-drop;
- быстрый, полный и пользовательский режимы, прогресс и отмена внешних процессов;
- ExifTool с JSON-выводом, раздельные PDF Info и XMP;
- qpdf, pdfcpu, PDFiD и pdf-parser через независимые subprocess-адаптеры;
- сохранение команды, версии, stdout, stderr, exit code и длительности каждого запуска;
- версия PDF, шифрование, подписи, объекты, object streams, xref, `/Prev`, `%%EOF`,
  JavaScript, вложения и формы;
- восстановление байтовых срезов инкрементальных ревизий и сравнение изменённых объектов;
- дерево PDF-объектов и ссылок, просмотр словаря, raw/decoded stream и read-only hex;
- полный qpdf JSON-индекс, включая логически развёрнутые объекты из `/ObjStm`;
- технический профиль происхождения: trailer `/ID`, XMP DocumentID/InstanceID,
  XMP History, следы приложений и сопоставление с ревизиями и сертификатами;
- независимые проверки pdfcpu: strict/relaxed validation, разрешения, формы,
  вложения и подписи в полностью офлайн-режиме;
- Poppler: независимые сведения PDF, перечни шрифтов и изображений, вложения,
  текстовый слепок и отрисовка реконструированных ревизий;
- постраничное визуальное сравнение соседних ревизий с долей изменившихся
  пикселей и отдельными diff-изображениями;
- JHOVE PDF-hul: форматная идентификация, well-formed/valid и диагностические сообщения;
- veraPDF: PDF/A и PDF/UA, нарушенные правила стандарта и отдельный feature-report;
- Apache PDFBox: независимое извлечение текста и XMP, копия с декодированными
  streams и запускаемый из интерфейса PDFDebugger;
- собственный локальный Java 21 runtime для JHOVE, veraPDF и PDFBox;
- структурная проверка ByteRange и офлайн-проверка подписей/сертификатов через pyHanko;
- безопасное перечисление и извлечение PDF-вложений;
- исследовательская QDF-копия, не заменяющая оригинал;
- PPTX: `core.xml`, `app.xml`, `custom.xml`, комментарии и их авторы, заметки,
  скрытые слайды, внешние связи и встроенные объекты;
- единая хронология с нормализацией PDF-, ISO- и Exif-дат и сохранением информации
  о часовом поясе;
- нейтральные правила расхождений, сравнение двух документов, отметки и выводы эксперта;
- русские названия параметров и пояснения при сохранении неизменных технических данных;
- HTML, JSON и DOCX-отчёты, ZIP-пакет с манифестом SHA-256 и сырыми результатами;
- пользовательский DOCX/DOTX-шаблон отчёта;
- настраиваемые пути инструментов и кнопка проверки установки;
- проверяемое по SHA-256 обновление через настраиваемый HTTPS-манифест.

Приложение не исполняет JavaScript или макросы, не открывает внешние связи и не
отправляет исследуемые документы в сеть. Обновления проверяются только при наличии
явно заданного URL манифеста.

## Запуск из исходников

Требуется Python 3.12+.

```powershell
.\setup.ps1
.\run.ps1
```

После подготовки окружения приложение также открывается двойным щелчком по
`Launch.vbs`, без консольного окна. Пути внешних инструментов выбираются в
настройках; доступность проверяется кнопкой «Проверить инструменты».
PDFiD и pdf-parser включены в `app/resources/tools`. Другие движки обнаруживаются
в PATH или по указанному пути. Наличие всех инструментов не требуется для запуска.
Точный состав EXE зависит от сценария сборки и доступных бинарников.

Headless-режим:

```powershell
.\run.ps1 --analyze "C:\evidence\sample.pdf" --mode full --output report.json
.\run.ps1 --analyze "C:\evidence\photo.jpg" --mode quick --output report.docx
.\run.ps1 --watch "C:\evidence\inbox" --mode quick
```

Поддерживаемые расширения отчёта: `.json`, `.html`, `.docx`, `.zip`.

## Тесты, EXE и установщик

```powershell
.venv\Scripts\python.exe -m pytest
.\build-preview.ps1
# Полная релизная цепочка с аудитом состава и возможной подписью:
.\build.ps1
```

Локальная тестовая сборка: `dist\DocumentForensicInspectorPreview\DocumentForensicInspectorPreview.exe`.
Она использует отдельный актуальный инвентарь окружения, не подписывается и не включает
внешние CLI-движки. Python устанавливать на машине запуска этой EXE не требуется.

Результат полной релизной цепочки: `dist\DocumentForensicInspector\DocumentForensicInspector.exe`. Если установлен Inno
Setup, дополнительно создаётся единый установщик
`dist\DocumentForensicInspector-Setup-0.4.2.exe`. Сборка onedir выбрана намеренно:
Qt/PySide6 остаются отдельными заменяемыми библиотеками, но пользователю всё равно
передаётся один setup-файл. Для Authenticode-подписи задайте
`DFI_CERTIFICATE_THUMBPRINT`; сертификат с закрытым ключом должен быть доступен в
хранилище текущего пользователя.

Сборочный сценарий также создаёт публичный архив исходников
`dist\DocumentForensicInspector-Source-0.4.2.zip`. В него не включаются исследуемые
документы, локальные базы и отчёты, загрузочный кэш, сторонние бинарники, приватные
ключи, каталоги build/dist и журналы.

Рабочие копии, SQLite, журналы и настройки находятся в
`%LOCALAPPDATA%\DocumentForensicsLab`.

## Ограничение форматов

Глубина проверки зависит от формата и установленных инструментов. Неизвестные файлы
получают базовую карточку и доступные данные ExifTool. Название «универсальная» не
означает полный разбор любого формата. Подробнее: [архитектура](docs/ARCHITECTURE.md)
и [известные ограничения](docs/KNOWN_LIMITATIONS.md).
