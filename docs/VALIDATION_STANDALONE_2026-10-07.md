## Исправления, обнаруженные при проверке

1. В готовой программе ffprobe и остальные движки выбираются из поставки.
   Отсутствующий встроенный файл не заменяется произвольной версией из PATH.
2. Сохранённые стандартные пути пересчитываются после переноса. Явно указанный
   пользовательский инструмент вне папки программы остаётся выбранным.
3. veraPDF 1.30.2 ломает JSON-отчёт о признаках на `lowLevelInfo`. Для этого
   отчёта используется XML без потери разделов; ошибочный XML не считается успехом.
4. PNG-модуль Poppler обрезает длинный префикс Windows. Отрисовка выполняется
   в короткой временной папке, затем картинки переносятся в исследование.
5. Автоматические настройки veraPDF направлены в рабочую папку. Установка
   программы остаётся неизменной; запись рядом с JAR-файлами не требуется.

В руководстве убраны указания отдельно устанавливать движки. Все страницы
отрисованы, изменённые страницы 3, 15 и 16 просмотрены. Автоматическая проверка
подтвердила текст, ссылки, шрифты, закладки и отсутствие перекрытий элементов.
