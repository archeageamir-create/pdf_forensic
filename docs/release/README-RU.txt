DOCUMENT FORENSIC INSPECTOR 0.5.1 — АНСЭ

Программа для исследования файлов и метаданных. Разработана ТОО «АНСЭ».
Бесплатная поставка. Регистрация, ключ и подписка не нужны.

КАК УСТАНОВИТЬ
1. Запустите DocumentForensicInspector-Setup-0.5.1.exe.
2. Прочитайте условия использования и подтвердите установку.
3. Откройте Document Forensic Inspector с рабочего стола или из меню «Пуск».
Установка выполняется для текущего пользователя без прав администратора.
Папка программы и ярлык создаются автоматически.
Python, Java, Qt и анализаторы входят в установщик. Интернет для установки
и исследования файлов не требуется. Ничего скачивать через командную строку не надо.

Первый запуск: «Инструменты → Проверить установку». Все встроенные инструменты
должны быть доступны. Если антивирус удалил файл, проверьте журнал защиты и
источник установщика. Не отключайте защиту целиком.

КАК НАЧАТЬ
Перетащите файл в окно или нажмите «Добавить файлы». Для первого просмотра
подойдёт быстрый режим. Затем откройте «Обзор», «Результаты» и «Хронология».
Источник и исходное значение помогают проверить смысл каждого наблюдения.
Карточка проекта нужна, если хотите объединить несколько файлов в исследование.
«Очередь и папки» позволяет добавлять файлы пачкой и наблюдать за папкой.
Наблюдение работает, пока открыта программа. Самостоятельный фоновый режим
описан в руководстве разработчика; автоматически при входе в Windows не запускается.

«Сохранить отчёт» создаёт Word, HTML, JSON или ZIP с журналами и результатами.
Сохранение идёт в фоне; просмотр других файлов остаётся доступным.
Помощник предлагает пояснения и заготовки заметок. Проверяйте основания сами.
Даты метаданных не доказывают время реального события. НПВ не равнозначно
предварительному сообщению о невозможности дать заключение эксперта.

РУКОВОДСТВО И ЭКРАН
F1 открывает руководство со скриншотами. Оно также лежит рядом с установщиком.
Учебные файлы находятся в _internal/docs/user-guide/examples внутри программы.
Окно можно растягивать. На небольшом экране скройте список проектов через
«Вид → Проекты и файлы» или Ctrl+B. Повторное нажатие возвращает список.
Ширину столбцов можно менять мышью. Таблицы и длинные формы прокручиваются.

ОБНОВЛЕНИЕ И ДАННЫЕ
Закройте программу и запустите новый установщик в прежнюю папку.
Исследования хранятся отдельно: %LOCALAPPDATA%\DocumentForensicsLab.
Перед обновлением скопируйте эту папку целиком, когда программа закрыта.
Удаление программы через Windows не удаляет исследования. Чтобы перенести
их на другой ПК, закройте обе копии и перенесите эту папку целиком.
В отчётах остаются исходные пути. После переноса исходники могут потребовать
повторного выбора. Не переносите только файл базы: нужны и рабочие копии.

ПЕРЕНОСНАЯ ВЕРСИЯ
Распакуйте весь ZIP. Откройте DocumentForensicInspector.exe.
Папка _internal должна оставаться рядом. Запуск прямо из ZIP не поддерживается.
«Переносная» означает отсутствие установки. По умолчанию исследования всё равно
сохраняются в профиле Windows, а не на флешке. Не запускайте две копии одновременно
с одной папкой данных.

ФАЙЛЫ КОМПЛЕКТА
Setup — обычный установщик. Windows.zip — переносная версия.
Source — исходники оболочки и инструкции сборки.
PDF — руководство. REQUIREMENTS — требования и ограничения.
USER_AGREEMENT — условия использования. Лицензии и перечень компонентов входят
в программу. Исходники зависимостей и условия их получения описаны в compliance.
SHA256SUMS.txt — контрольные суммы файлов комплекта.
