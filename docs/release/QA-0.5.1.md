# Проверка версии 0.5.1 — 9 октября 2026 года

Проверен Windows x64 EXE с SHA-256
`8dc55454961a199fc185df20516d2e9a3d390876ec3582a999a1ac51d5904575`.
Контрольные суммы установщика, архивов и документов указаны в SHA256SUMS.txt.

## Что проверено

- Прошли 213 автоматических тестов.
- Программа открывает настоящее окно Windows и обрабатывает очередь в фоне.
  Все 11 встроенных инструментов работают с пустым тестовым профилем и PATH,
  содержащим только системные папки Windows. Внешние Python и Java не нужны.
- Проверены полное исследование PDF с ревизиями и изображениями страниц,
  JPG, WAV и DOCX, сохранение JSON, Word, HTML и ZIP. Исходники не изменились.
- Переносная сборка распакована в отдельную папку с кириллицей. Сверены 2695
  записей манифеста. Очередь из 48 учебных файлов обработана за 33,98 секунды;
  вторую часть добавили во время работы. Шесть намеренно повреждённых файлов
  получили ожидаемый частичный результат. Это измерение на проверочном ПК,
  а не обещание скорости на любом устройстве. После этой проверки обновлены
  только сопроводительные документы; код и исполняемые файлы не менялись.
- Проверены установка в длинный путь, повторная установка, работа всех движков
  после обновления и удаление отдельного тестового экземпляра. Устаревший файл
  во внутренней папке удаляется, посторонний файл в корне сохраняется.
  Удаление тестового экземпляра не затронуло основную установленную программу.
- Проверены шесть вариантов окна: 1366×728 при 100%, 1093×574 при 125%,
  911×480 при 150%, 1097×577 при 175%, 960×500 и 1920×1040 при 200%.
  В каждом проверены восемь вкладок, карточка проекта, настройки и окно
  «О программе». Закрытие, сохранение и прокрутка доступны.
- Новая сборка ffprobe сравнена с прежней на 12 примерах: WAV, MP3, FLAC,
  OGG, M4A, OPUS, AVI, MKV, MOV, MP4, WEBM и MOV со сжатым заголовком.
  Полные результаты разбора контейнера и дорожек совпали.
- Руководство содержит 20 страниц, встроенные шрифты, закладки и снимки
  программы. Номер версии обновлён. Учебные примеры обозначены.
- Проверены хеши 229 файлов исходников зависимостей и 158 файлов рецептов,
  патчей и сведений о сборке. Дополнение исходников собрано из трёх частей;
  контрольная сумма полученного ZIP совпала с исходной.
- Архив кода проверен на случайное включение баз исследований, ключей,
  пользовательских путей и исполняемых файлов. Лицензии входят в комплект.

## Что исправлено в этой версии

Встроенный ffprobe собран из исходников FFmpeg с динамическими библиотеками
и условиями LGPL. Добавлена поддержка сжатых заголовков MOV: первый вариант
сборки не проходил этот пример, окончательный проходит.

Для библиотек Poppler найдены точные исходники, рецепты и патчи поставщика.
Нужные библиотеки Visual C++ лежат рядом с инструментом. Удалены неиспользуемые
компоненты. Дополнен комплект исходников Java, Pillow и Qt.

Слишком глубокие пути к лицензионным материалам сокращены. Полные рецепты
сборки перенесены в отдельный комплект исходников: они не нужны при запуске,
но раньше мешали установке в длинную папку. Повторный тест установки прошёл.

## Границы проверки

Экранные варианты проверены средствами Qt с шрифтами Windows, без шести
физических мониторов. Проверка клавиатурного управления не заменяет отдельное
испытание со всеми программами чтения с экрана.

Чистая виртуальная машина Windows без установленных программ не использовалась.
Вместо неё проверены пустой профиль, системный PATH и наличие требуемых DLL
в комплекте. Проверка на отдельной чистой Windows всё ещё полезна перед
массовым развёртыванием.

У сборки нет доверенной цифровой подписи издателя. Исходники зависимостей
сопоставлены с поставкой и проверены по хешам. Самостоятельно пересобран FFmpeg;
побайтовое воспроизведение остальных сторонних сборок не заявляется.

Программа помогает разбирать данные. Она не подтверждает подлинность файла
автоматически и не принимает процессуальные решения за эксперта.
