# Исходники компонентов версии 0.5.1

В папке распространения есть отдельная папка исходников зависимостей.
Для обычного запуска программы она не нужна. Она нужна тому, кто хочет
изучить, изменить или пересобрать сторонние компоненты.

Комплект состоит из двух частей:

1. `Dependency-Sources-0.5.0.zip` — восемь исходных архивов. Их версии в 0.5.1
   не менялись. Архив разбит на части; рядом находятся контрольные суммы
   и сценарий сборки целого ZIP.
2. Дополнение для 0.5.1 — исходники библиотек Poppler, точные рецепты и патчи
   поставщика, исходные Java-архивы и сборочные POM-файлы, сценарии сборки
   Temurin и нашей версии ffprobe. Сюда же входит обновлённый каталог.

Для восстановления дерева сборки поместите восемь основных архивов и
`SOURCE_ARCHIVES_MANIFEST.json` в `third_party_sources/archives`, а содержимое
`supplement` из дополнения — в одноимённую вложенную папку. Каталог
`compliance/source-records` уже входит в исходники самой программы.

`python scripts/verify_source_delivery.py` сверяет исходники и рецепты с
зафиксированными SHA-256. Он также сравнивает DLL Poppler с файлами конкретных
пакетов conda-forge. Отсутствующий архив, изменённый патч или отсутствующая
личная DLL движка останавливают проверку. Команду `--seal` применяют только
при сознательной подготовке новой версии, после проверки происхождения файлов.

## ffprobe

Исходники FFmpeg не изменялись. Сценарий `scripts/build_ffprobe.py` собирает
ffprobe и отдельные заменяемые DLL под Windows x64 через MSYS2 UCRT64.
Установите GCC, make, nasm и diffutils через MSYS2. Затем запустите сценарий
из Python 3.12. Он проверяет исходный архив и сохраняет конфигурацию,
версии инструментов и лицензии рядом с результатом. Имена пакетов и версии
есть в `ffmpeg/build-information/toolchain.txt` установленной программы.

Используется LGPL-2.1-or-later. GPL-функции, внешние мультимедийные библиотеки,
сеть, кодировщики и запись медиаконтейнеров отключены. Для чтения сжатых
заголовков сохранены zlib, bzip2 и liblzma. Само исследование
пользуется чтением контейнера, потоков и метаданных. FFmpeg работает отдельным
процессом. Его DLL можно заменить совместимой изменённой сборкой.

Готовый архив нашей сборки также приложен к дополнению для удобства повторной
сборки оболочки. Положите его в `.downloads/runtime`. Для самостоятельно
пересобранного или изменённого ffprobe проверьте результаты, затем намеренно
обновите размер и SHA-256 в `compliance/runtime-dependencies.lock.json`.
Сценарий не принимает несовпадающую контрольную сумму автоматически.

## Poppler и Java

Для Poppler сохранены исходники, рецепты, патчи и лицензии точных пакетов
conda-forge. Их связь с поставляемыми DLL установлена по SHA-256.
В программе оставлены шесть используемых утилит и их DLL. Visual C++ Runtime
скопирован из закреплённого пакета qpdf; он размещён рядом с Poppler.

Для Java-компонентов сохранены исходные JAR-файлы, POM и родительские POM
точных версий, найденных внутри поставляемых JAR. Для пустого служебного
`listenablefuture` достаточно POM: сами классы находятся в Guava.
Для сборного `pdfbox-app` приложен полный исходный архив PDFBox.
Отдельно сохранены исходники JHOVE, veraPDF-apps, OpenJDK и точный commit
сценариев сборки Temurin, указанный в файле `java/release`.

Условия и права сторонних разработчиков остаются в силе. Получение исходников,
изменение LGPL-компонентов и отладка этих изменений не запрещены. Условия
письменного предложения исходников находятся в `SOURCE_OFFER.md`.

## Pillow и Qt

Pillow 12.3.0 содержит небольшой LGPL-адаптер для загрузки FriBiDi. Приложены
полные исходники Pillow, его Windows-сценарии сборки, FriBiDi и зависимости
шрифтового модуля. GPL-компонент libimagequant в используемом Pillow отключён.
Совместимый пересобранный модуль `_imagingft.cp312-win_amd64.pyd` можно заменить
в `_internal/PIL`. Для сборки используйте инструкции `winbuild` из полного
репозитория Pillow, Python 3.12 x64 и Microsoft C++ Build Tools; исходные архивы
зависимостей можно положить в его кэш загрузок. Исходники raqm и LGPL-адаптера
находятся в `src/thirdparty` самого Pillow.

Для Qt и PySide6 приложены полные исходные архивы версии 6.11.2.
QtPdf, QtVirtualKeyboard и неиспользуемые QML-модули в сборку не включены.
Дополнительные лицензии QtBase, QtSvg и QtImageFormats сохранены в комплекте
лицензий. Порядок замены Qt/PySide6 описан в `LGPL_COMPLIANCE.md`.
