# Руководство пользователя

[Открыть PDF](DocumentForensicInspector-User-Guide-RU.pdf) — 20 страниц на русском,
формат A4, альбомная ориентация. Редакция 7 октября 2026 года, Universal Preview.
Оглавление и закладки кликабельны. В программе PDF открывается по F1, через меню
«Справка» или кнопку «Как пользоваться» на стартовом экране.

## Что внутри

- Запуск, первый анализ и организация проектов.
- Пояснения к результатам, статусы, исходные поля и поиск.
- Сопоставление дат с известным и неизвестным часовым поясом.
- Заметки, собственные выводы, Word/HTML/JSON и ZIP-пакет.
- Очередь и наблюдение за папкой, доступные форматы и инструменты.
- Устранение проблем, хранение данных, словарь и памятка по НПВ в РК.

Все иллюстрации — снимки реальных Qt-виджетов этой версии приложения. Исследуемые
файлы, имена и записи искусственно созданы для обучения, а не взяты из материалов
пользователя. Примеры находятся в [examples](examples). DOCX содержит одну
сохранённую вставку и две временные записи одного момента с разными смещениями.
JPEG содержит временную запись без пояса. Снимки сделаны встроенными проверками;
набор результатов с внешними инструментами может быть шире.

## Как обновить

Сначала внесите изменения в интерфейс, затем заново снимите экраны и соберите PDF.
Для захвата нужны обычные зависимости проекта; для вёрстки отдельно нужен
`reportlab>=4,<5`. Он не требуется пользователю готовой программы.

```powershell
.\.venv\Scripts\python.exe scripts\capture_user_guide.py
python -m pip install "reportlab>=4,<5" pypdf Pillow
python scripts\build_user_guide.py
```

Генератор ожидает Segoe UI в `C:/Windows/Fonts`; путь можно передать через `--fonts`.
Файлы шрифтов не копируются в репозиторий. Скрипт встраивает подмножества шрифтов в PDF.
Если для документа используется отдельное Python-окружение, замените `python` его путём.

Итог: `output/pdf/DocumentForensicInspector-User-Guide-RU.pdf`. Идентичная копия в этой
папке включается обоими PyInstaller-spec в `_internal/docs/user-guide` вместе с примерами.
Захват использует отдельное хранилище в `tmp/pdfs/guide-capture`, не базу пользователя.
При повторной генерации даты файловой системы, UUID и хеши учебных файлов могут измениться.

Проверка перед поставкой (Poppler должен быть в PATH):

```powershell
New-Item -ItemType Directory -Force tmp/pdfs/rendered | Out-Null
pdftoppm -r 115 -png output/pdf/DocumentForensicInspector-User-Guide-RU.pdf tmp/pdfs/rendered/guide
.\.venv\Scripts\python.exe scripts\verify_user_guide.py
```

Просмотрите все 20 отрисованных страниц, затем собирайте приложение. Проверка PDF
проверяет текст, закладки, ссылки, встроенные шрифты и совпадение копий; контактные
листы помогают проверить вёрстку. `package_preview.py` отклоняет архивирование,
если встроенные руководство или учебные файлы расходятся с текущими исходниками.

7 октября 2026 года. Она не заменяет действующий процессуальный порядок и решение эксперта.
