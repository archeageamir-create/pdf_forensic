# Contributing

By submitting a contribution, you certify that you have the right to submit it
under the Apache License 2.0 used by this project.

Contributions must use the Developer Certificate of Origin 1.1 sign-off:

```text
Signed-off-by: Full Name <email@example.com>
```

Use `git commit -s` to add the sign-off. Do not submit confidential evidence,
client documents, analysis databases, generated reports, private keys,
third-party binaries or code copied from a source whose license is unknown.

New dependencies require all of the following before merge:

- exact package name and version;
- SPDX license expression;
- upstream project and source URL;
- complete license and notice files;
- redistribution and corresponding-source assessment;
- update to `compliance/components.json` and regenerated `SBOM.spdx.json`.

Developer Certificate of Origin 1.1:
<https://developercertificate.org/>
