# Written source-code offer

Document Forensic Inspector 0.5.0 contains unmodified third-party components
licensed under the GPL, LGPL and MPL. Their exact versions, licenses and source
locations are listed in `THIRD_PARTY_NOTICES.md`, `SBOM.spdx.json` and
`compliance/runtime-dependencies.lock.json`.

For every recipient of the Windows installer, ANSE LLP (ТОО «АНСЭ») offers the
complete corresponding source code for those components, including the scripts
and information used to control compilation and installation, in a
machine-readable form. This offer is valid to any third party until at least
22 July 2032. The charge, if physical media is requested, will not exceed the
reasonable cost of physically providing the source.

Request the source through the public issue tracker:
https://github.com/archeageamir-create/pdf_forensic/issues

The preferred delivery is a downloadable source archive. Exact upstream source
links are also recorded in `compliance/THIRD_PARTY_SOURCES.json`. No restriction
is imposed on reverse engineering performed to debug modifications to LGPL
components.

This offer concerns third-party corresponding source only. It does not include
private case files, analysis databases, reports, signing private keys or other
user data.
