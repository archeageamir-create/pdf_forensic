# Document Forensic Inspector

Локальная лаборатория исследования файлов для русскоязычного эксперта. Пользователь
добавляет материалы, узнаёт, что содержится в файле и откуда получены наблюдения,
проверяет значимые детали, сохраняет свои выводы и воспроизводимый отчёт.

## Platform

Windows desktop, Python 3.12+, PySide6/Qt. Режим интерфейса: Operate.
Существующий светлый интерфейс Windows / Segoe UI сохраняется и развивается.

## Принципы

- Подбор анализаторов по содержимому, независимость от расширения.
- Сначала объяснимые результаты; детали инструментов раскрываются по необходимости.
- Оригинал читается; анализаторы получают отдельную копию с проверенными хешами.
- Каждое наблюдение связано с источником и исходным значением.
- Завершение анализа не означает подлинность файла. Отсутствие данных не означает
  отсутствия редактирования. Объём и ошибки проверки видны пользователю.
- Сеть, макросы и внешние ссылки не нужны для анализа.

## Направление развития

Общий интерфейс к специализированным консольным утилитам: PDF, Office, изображения,
аудио/видео, архивы, затем новые адаптеры. Постоянная очередь и наблюдение за папкой
должны убирать ручное повторение действий. Уже работающие PDF-инструменты сохраняются.
